# 구구팡 슬라임

같은 색 슬라임 4개를 모으고 **곱셈 문제를 풀면** 터지는, 초등학생용 낙하형 연쇄 퍼즐 웹게임입니다.
뿌요뿌요(통) 규칙을 그대로 따르되, 연쇄의 **첫 번째 터짐**에만 곱셈 문제가 나옵니다.

## 규칙
- 1~9 숫자가 적힌 젤리 슬라임이 두 개씩 떨어집니다.
- 같은 색 4개 이상이 붙으면, 그 묶음 중 슬라임 2개의 숫자로 곱셈 문제가 나옵니다 (문제에 쓰인 슬라임이 반짝임).
- 정답 → 펑! 그 뒤 이어지는 연쇄는 문제 없이 자동으로 터집니다.
- 오답 → 2초 동안 입력할 수 없고, 두 번 틀리면 힌트가 나옵니다. 문제를 푸는 동안 내 보드는 멈추지만 상대는 계속 움직입니다.
- 점수, 방해 슬라임(70점당 1개), 상쇄, 전체 클리어 보너스, 숨은 13번째 줄, ✕칸 게임 오버는 원작과 같습니다.

## 모드
- **컴퓨터와 대결**: 초급 / 중급 / 고급 (컴퓨터도 곱셈 문제를 풀며, 수준에 따라 푸는 속도와 실수 비율이 다릅니다)
- **온라인 대결**: 방 만들기(2~4명) → 방 목록에서 들어가기 → 준비 완료 → 방장이 시작
  - 대기실·게임 중(💬 버튼)·결과 화면에서 친구에게 상용구 8개(`public/js/emotes.js`)를 보낼 수 있습니다. 직접 쓴 글은 보낼 수 없고, 3초에 한 번만 보낼 수 있으며, "친구 메시지 끄기"로 받은 메시지를 숨길 수 있습니다.
- **랭킹**: 학교(검색해서 선택)와 닉네임으로 온라인 대결 기록을 저장합니다.
  - 개인 승리 횟수 랭킹, 개인 승률 랭킹(10판 이상), 학교 랭킹(학교 학생들의 승리 횟수 합계)
  - 이름이 같은 학교는 검색 결과에 위치(예: 경기 포천시)가 함께 나와서 골라 쓸 수 있습니다.
  - 30초보다 짧은 판은 기록하지 않고, 대결 도중 나가면 패배로 기록합니다.
  - 닉네임과 방 이름에 비속어를 쓸 수 없습니다. (`public/js/profanity.js`에서 단어를 더하거나 뺄 수 있음)
- **티어** (온라인 대결만): 이기면 +25점, 지면 -10점, 지금 티어 아래로는 떨어지지 않아요(강등 보호).
  - 브론즈 0 · 실버 100 · 골드 250 · 플래티넘 450 · 다이아 750 · 마스터 1000점
  - 그랜드마스터·챌린저는 순위: 마스터 중 전국 TOP 30 / TOP 10
  - 티어가 생기기 전 기록은 승리 1번에 15점으로 처음 한 번 채웠어요.
  - 이름표(바탕색·테두리)로 홈 화면, 방 목록, 대기실, 게임 판, 결과 화면, 랭킹 어디서나 티어가 보여요. (`public/js/tiers.js`, `public/js/badge.js`)
- **랭킹**: 이번 주(매주 월요일 0시 한국 시간에 새로 시작) / 전체 × 티어·승리 횟수·승률·학교
- **칭호**: 순위·이번 주·승리·연승 칭호를 얻으면 칭호 도감에서 대표 칭호를 골라 이름표 옆에 달아요. 연쇄·정답·실력 칭호는 다음 업데이트에서 열려요. (`public/js/titles.js`)
- **혼자 연습**

## 실행 (내 컴퓨터에서)
```bash
npm install
npm run dev        # http://localhost:8787
```
Cloudflare의 실제 실행 환경을 내 컴퓨터에서 그대로 띄우므로, 온라인 대결과 랭킹까지 모두 확인할 수 있습니다.

## 학교 목록 만들기 (처음 한 번, 이후 1년에 한 번)
학교 검색에 쓰는 전국 초등학교 목록(`public/data/schools.json`)은 공식 데이터로 만듭니다.

**방법 1. NEIS 교육정보 개방 포털 (추천)**
1. https://open.neis.go.kr 에 가입하고 인증키를 신청합니다. (무료)
2. `NEIS_API_KEY=발급받은키 npm run schools`

**방법 2. 공공데이터포털 CSV**
1. 공공데이터포털에서 "전국초중등학교위치표준데이터" CSV를 내려받습니다.
2. `npm run schools -- --csv 내려받은파일.csv`

랭킹은 학교 코드로 저장되므로, 한 번 정한 방법을 계속 쓰세요. 만든 파일을 커밋하면 배포에 함께 올라갑니다.

## 배포 (Cloudflare 무료 플랜)
온라인 대결 서버는 Cloudflare **Workers + Durable Objects**로 동작합니다. (Pages가 아니라 **Workers**로 만들어야 합니다.)

1. Cloudflare 대시보드 → **Workers & Pages** → **Create application**
2. **Import a repository**(GitHub 저장소 가져오기)를 고르고 `newgame` 저장소를 선택
3. 프로젝트 이름은 `gugupang` (`wrangler.jsonc`의 name과 같아야 함), 배포 명령은 기본값 `npx wrangler deploy` 그대로 두고 **Deploy**
4. 끝나면 `https://gugupang.<내 계정 subdomain>.workers.dev` 주소로 접속할 수 있습니다.

이후 `main` 브랜치에 바뀐 내용이 합쳐지면 자동으로 다시 배포됩니다.
`wrangler.jsonc`에 필요한 설정(방 목록·랭킹 저장소, 대결방)이 모두 들어 있어서 따로 데이터베이스를 만들 필요가 없습니다.

### 무료 플랜으로 버틸 수 있는 양
- 대결 중에는 내 화면 정보를 1초에 최대 5번만 보냅니다.
- Cloudflare는 이런 메시지 20개를 요청 1건으로 세므로, 3분짜리 한 판에 한 명당 약 45건입니다.
- 무료 한도는 하루 10만 건이라, 대략 **하루 2,000명·판** 정도까지 무료입니다. 넘으면 그날은 온라인 대결이 막히고, 컴퓨터 대결·연습은 계속 됩니다.
- 사용자가 더 늘면 Workers 유료 플랜(월 $5)으로 올리면 됩니다.

## 오래된 브라우저 호환
학교 태블릿은 업데이트가 막혀 있는 경우가 많아서, 게임 코드(`public/js`)는 **ES2017 문법까지만** 씁니다. (크롬 61+, iOS 11+. ES 모듈을 쓰므로 이보다 오래된 브라우저는 열 수 없음)
- `??`, `?.`, `||=`, 괄호 없는 `catch {`, 객체 펼치기 `{ ...obj }` 같은 최신 문법은 쓰지 않습니다.
- 확인: `npm i acorn`을 임시 폴더에 설치하고 `public/js/*.js`를 `ecmaVersion: 2017, sourceType: 'module'`로 파싱해 모두 통과하는지 봅니다.
- `index.html` 안의 안전장치(ES5): 게임이 시작되지 못하면 빈 화면 대신 "업데이트해 주세요" 안내와 원인·브라우저 정보를 보여 줍니다. 게임이 정상 시작되면 `main.js` 끝에서 `window.__gameReady = true`로 알립니다.
- 학교망이나 태블릿 관리 프로그램이 `workers.dev` 주소 자체를 막은 경우는 코드로 해결할 수 없고, 안내 화면도 뜨지 않습니다.

## 구조
- `src/worker.js` – Cloudflare 서버: 방 목록 + 랭킹(Lobby), 대결방(GameRoom)
- `wrangler.jsonc` – Cloudflare 설정
- `public/js/core.js` – 보드·연쇄·점수 규칙
- `public/js/player.js` – 한 플레이어의 게임 진행, 온라인 상대 화면
- `public/js/ai.js` – 컴퓨터 상대
- `public/js/render.js` – 캔버스 그리기
- `public/js/identity.js` – 지역·학교·닉네임 규칙
- `public/js/main.js` – 화면/메뉴/조작/온라인 연결/랭킹 화면
