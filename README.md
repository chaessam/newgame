# 구구팡 슬라임

같은 색 슬라임 4개를 모으고 **곱셈 문제를 풀면** 터지는, 초등학생용 낙하형 연쇄 퍼즐 웹게임입니다.
뿌요뿌요(통) 규칙을 그대로 따르되, 연쇄의 **첫 번째 터짐**에만 곱셈 문제가 나옵니다.

## 규칙
- 1~9 숫자가 적힌 젤리 슬라임이 두 개씩 떨어집니다.
- 같은 색 4개 이상이 붙으면, 그 묶음 중 슬라임 2개의 숫자로 곱셈 문제가 나옵니다 (문제에 쓰인 슬라임이 반짝임).
- 정답 → 펑! 그 뒤 이어지는 연쇄는 문제 없이 자동으로 터집니다.
- 오답 → 1초 동안 입력할 수 없고, 두 번 틀리면 힌트가 나옵니다. 문제를 푸는 동안 내 보드는 멈추지만 상대는 계속 움직입니다.
- 점수, 방해 슬라임(70점당 1개), 상쇄, 전체 클리어 보너스, 숨은 13번째 줄, ✕칸 게임 오버는 원작과 같습니다.

## 모드
- **컴퓨터와 대결**: 초보 / 중수 / 고수 (컴퓨터도 곱셈 문제를 풀며, 수준에 따라 푸는 속도와 실수 비율이 다릅니다)
- **온라인 대결**: 방 만들기(2~4명) → 방 목록에서 들어가기 → 준비 완료 → 방장이 시작
- **혼자 연습하기**

## 실행
```bash
npm install
npm start          # http://localhost:3000
```
같은 네트워크의 다른 컴퓨터/태블릿에서는 `http://<서버 컴퓨터 IP>:3000` 으로 접속하면 함께 대결할 수 있습니다.
인터넷에 공개하려면 Node.js를 지원하는 호스팅(Render, Railway, Fly.io 등)에 올리면 됩니다 (`PORT` 환경 변수 지원).

## 조작
| 키 | 동작 |
|---|---|
| ← → | 옮기기 |
| ↓ | 빨리 내리기 |
| ↑ / X | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| 숫자 + Enter | 답 입력 |
| Esc | 일시정지 (온라인 제외) |

터치 기기에서는 화면 아래 버튼과 화면 키패드를 사용합니다.

## 구조
- `server.js` – 정적 파일 + WebSocket 방/로비 서버
- `public/js/core.js` – 보드·연쇄·점수 규칙
- `public/js/player.js` – 한 플레이어의 게임 진행, 온라인 상대 화면
- `public/js/ai.js` – 컴퓨터 상대
- `public/js/render.js` – 캔버스 그리기
- `public/js/main.js` – 화면/메뉴/조작/온라인 연결
